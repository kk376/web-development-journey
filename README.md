# Web Development Journey 🌐

A structured, hands-on learning roadmap, concept documentation, and project archive for modern full-stack web development.

---

## 📚 Curriculum Structure

This repository follows a chapter-by-chapter progression covering core web technologies:

```text
web-development-journey/
├── 01_html/                                  # HTML5 structure, semantic markup, forms, media
├── 02_css/                                   # CSS3 styling, box model, positioning, Flexbox
├── 03_projects/                              # Hands-on landing pages & component builds
├── 04_javascript/                            # Core JS, variables, functions, data structures
└── 05_dom/                                   # Document Object Model & DOM manipulation
```
